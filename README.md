# 📦 Stock Management System

A web application for **stock management and inventory control**, allowing users to manage products, record stock entries and exits, and monitor inventory through a dashboard.

> 🚧 **Project Status:** In Development

## 🎯 Objective

The main objective of this project is to develop a simple and intuitive application that allows businesses to manage their stock in a centralized way, reducing errors and making inventory management easier.

## 🚀 Features

* 🔐 User authentication and management
* 📦 Product management
* 📥 Stock entry registration
* 📤 Stock exit registration
* ⚠️ Low-stock alerts
* 📊 Dashboard with relevant indicators
* 📋 Operation history
* 🔎 Product search and filtering
* 👥 Administrator and Employee roles
